# Lamar — Cybersecurity Engineering
### Central Repository for Academic Activities and Projects

Official repository for managing, developing, and versioning practical labs, research projects, and coursework for the **Cybersecurity Engineering** program. 

This space centralizes source code, testing tools, automation scripts, and technical documentation generated throughout the academic journey, applying industry standards in secure development and system architecture.

---

## 🛠️ Technology Stack & Environment

* **Version Control:** Git & GitHub (Managed via feature branches and semantic commits).
* **Execution Environments:** Node.js / TypeScript, Python, and isolated virtual environments.
* **Infrastructure & Virtualization:** Docker containers for controlled lab deployments and secure penetration testing.
* **Operating Systems:** Linux-based environments (Debian/Ubuntu/Kali) for running network scripts and auditing tools.

---

## ⚙️ Applied Engineering Principles

* **Clean Code & Design Patterns:** Decoupled code, SOLID principles, and strict typing.
* **Security by Design:** Proactive mitigation of vulnerabilities (OWASP Top 10), strict secret management (environment variables), and static code analysis.
* **Traceability:** Documentation for each deliverable, including flowcharts, risk assessments, or technical reports as applicable.
